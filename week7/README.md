# Week 7 · Capstone — put it all together

Goal: build a "repo assistant" CLI agent that uses everything.

Requirements:
- uses at least one custom tool you wrote;
- delegates a security pass and a docs pass to two subagents with scoped tools;
- applies a skill to shape the final summary;
- writes a REPORT.md and verifies it exists and is non-empty;
- has `maxTurns`, a budget cap, and try/catch error handling.
